# Inginv domain glossary

**Artifact** — A file under analysis, such as an APK, DEX, native library, keystore or runtime dump.

**Evidence** — A reproducible observation tied to an artifact fingerprint and an exact source location or runtime capture.

**Finding** — A security or engineering conclusion supported by one or more evidence records. A finding is not the same thing as a suspicious string.

**Capability** — Behavior implemented or authorized by software. Capability does not imply that the behavior was executed.

**Runtime observation** — State or behavior directly observed on a device at a specific time.

**Correlation** — Independent static and runtime evidence that support the same claim.

**Command path** — The trace from a remote/local task identifier through dispatch, policy/task logic and controller code to the eventual Android/framework primitive.

**Trust boundary** — A point where data or authority crosses between independently trusted actors, processes or systems.

**Sanitized report** — A report from which credentials, private keys, device identifiers and unrelated user data have been removed or replaced with non-secret metadata.
